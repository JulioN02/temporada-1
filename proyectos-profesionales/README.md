## Criterio común de "hecho" (nivel profesional)

Un proyecto cuenta como terminado cuando tiene:

- GitHub + README + demo + arquitectura + screenshots + changelog + artículo o video
- ADR donde haya decisiones de arquitectura
- Tests y OpenAPI
- Docker (reproducible)
