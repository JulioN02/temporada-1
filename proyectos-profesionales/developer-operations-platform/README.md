# Developer/Operations Platform

Proyecto profesional **OPCIONAL** de la Temporada 1. Documentación pedagógica en Obsidian → `Proyectos profesionales/Developer Operations Platform.md`.

> Mini plataforma interna para registrar la operación de tus propios sistemas. **Sin intentar ser** Datadog, Grafana ni Kubernetes.

Estado: 🔲 Pendiente (idea — scaffolding, opcional)

## Qué es

Una plataforma pequeña para llevar el registro y la salud de las aplicaciones que construyes:

| Registro | Qué captura |
|---|---|
| Applications | Aplicaciones conocidas |
| Services | Servicios internos de cada aplicación |
| Environments | Dev / staging / producción |
| Deployments | Cuándo y qué se desplegó |
| Health Checks | Estado de salud de cada servicio |
| Logs | Registro de eventos y errores |
| Incidents | Incidencias y su resolución |

## Para qué sirve

Su gracia no es ser una herramienta de monitoreo a escala empresarial. Su valor:

- **Te prepara para temporadas posteriores**: observabilidad, DevOps y operación (Temporadas 3 y 5)
- Te obliga a pensar en el ciclo de vida de un servicio: desplegar, monitorear, diagnosticar
- Conecta con lo aprendido en los labs de engineering (rate limiting, caching, retries) aplicado a operación real
