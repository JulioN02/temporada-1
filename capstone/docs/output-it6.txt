# Iteration 6 — Audit API + Observability + OpenAPI (T-6-1..T-6-6)

## What landed

- GET /api/audit (R-AUD-4): entity/action/from/to filters + pagination,
  newest-first; audit:read = admin/auditor only (operator → 403).
- R-AUD-3: login audit payloads verified actor/outcome/ip only — no
  credentials (append-only + rollback parity already proven at F-7/Batch A).
- GET /api/status (R-OBS-2 + ADR-6): any authenticated user →
  {version, uptimeSeconds, db, timestamp, queues}. queues = pg-boss
  reachability (DEV: pg-boss v12 has no ping(); bounded SQL ping of
  pgboss.queue via the pool, 500ms — never blocks).
- Request logs (R-OBS-3): one parseable JSON line per request with
  method/path/status/durationMs/requestId; path captured at request start
  (mounted routers rewrite req.path); redact verified: no token/password
  values in any line.
- OpenAPI 3.1 (R-DOC-1/2): spec generated at startup from the SAME zod DTOs
  (extendZodWithOpenApi bootstrap — zod v4 dual-build + per-instance method
  copying discovery); self-hosted Swagger UI at /api/docs (offline,
  swagger-ui-dist assets); money = string pattern ^\d+\.\d{2}$; notification
  types enum from NOTIFICATION_TYPES; /api/docs.json served.
- Contract scans (T-6-5): R-NFR-3 cumulative gate (63/63 requirement IDs in
  test names + strict tsconfig flags), R-NFR-4 (controllers no SQL, services
  no runtime express/pg), R-DOC-2 (no static openapi.json in src/).
