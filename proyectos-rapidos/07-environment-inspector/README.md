# 07 · Environment Inspector

Proyecto rápido de 1–3 días. Documentación en Obsidian → `Proyectos rápidos/Proyectos Rápidos.md`.

Estado: 💡 Idea

## Qué hace

Detecta herramientas instaladas (Node, NPM, Docker, PostgreSQL, Git) y muestra ✓/✗ por cada una.

## Qué problema resuelve

Verificar de un vistazo si un entorno de desarrollo está listo, antes de empezar a configurar.

## Qué aprendes

- Ejecución de procesos: invocar comandos y leer su salida
- Detección de entorno: `which`/`--version`, variables de entorno
- Reporte en consola: salida clara por herramienta

## Preguntas guía

1. ¿Qué problema resuelve?
2. ¿Qué aprendí?
3. ¿Qué parte fue difícil?
4. ¿Qué haría diferente?
