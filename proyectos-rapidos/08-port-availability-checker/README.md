# 08 · Port Availability Checker

Proyecto rápido de 1–3 días. Documentación en Obsidian → `Proyectos rápidos/Proyectos Rápidos.md`.

Estado: 💡 Idea

## Qué hace

Dado `localhost`, comprueba la disponibilidad de puertos típicos: 22, 80, 443, 3000, 5432.

## Qué problema resuelve

Saber si un servicio ya está corriendo o si un puerto está libre, antes de levantar algo nuevo.

## Qué aprendes

- Sockets: conexión TCP a un host/puerto, apertura y cierre
- Networking: puertos, servicios comunes y sus protocolos
- Conecta con networking (Temporada 4)

## Preguntas guía

1. ¿Qué problema resuelve?
2. ¿Qué aprendí?
3. ¿Qué parte fue difícil?
4. ¿Qué haría diferente?
