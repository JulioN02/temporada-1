# 03 · API Health Checker

Proyecto rápido de 1–3 días. Documentación en Obsidian → `Proyectos rápidos/Proyectos Rápidos.md`.

Estado: 💡 Idea

## Qué hace

Dada una URL, devuelve: STATUS, LATENCY, STATUS CODE, SSL y TIMESTAMP.

## Qué problema resuelve

Saber si una API está viva y sana, con métricas simples, sin levantar una plataforma de monitoreo.

## Qué aprendes

- HTTP: peticiones, respuestas, códigos de estado
- Latencia: medición de tiempos de respuesta
- SSL: verificación del certificado
- Conecta con la futura observabilidad (Developer/Operations Platform, Temporadas 3 y 5)

## Preguntas guía

1. ¿Qué problema resuelve?
2. ¿Qué aprendí?
3. ¿Qué parte fue difícil?
4. ¿Qué haría diferente?
