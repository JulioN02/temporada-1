# 06 · HTTP Request Replay

Proyecto rápido de 1–3 días. Documentación en Obsidian → `Proyectos rápidos/Proyectos Rápidos.md`.

Estado: 💡 Idea

## Qué hace

Guarda una petición HTTP (método, headers, body) y la reproduce cuando quieras.

## Qué problema resuelve

Reproducir una petición exacta para depurar un bug o probar un endpoint, sin depender de herramientas externas.

## Qué aprendes

- HTTP: método, headers, body, cómo se serializa una petición
- Serialización: guardar y restaurar una petición tal cual fue
- Mini tool de desarrollo: una utilidad que acelera el trabajo diario

## Preguntas guía

1. ¿Qué problema resuelve?
2. ¿Qué aprendí?
3. ¿Qué parte fue difícil?
4. ¿Qué haría diferente?
