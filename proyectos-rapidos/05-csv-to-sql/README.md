# 05 · CSV → SQL

Proyecto rápido de 1–3 días. Documentación en Obsidian → `Proyectos rápidos/Proyectos Rápidos.md`.

Estado: 💡 Idea

## Qué hace

Dado un archivo `products.csv`, genera sentencias `INSERT INTO products ...` listas para ejecutar.

## Qué problema resuelve

Cargar datos desde planillas a una base sin escribirlos a mano, con correcto escape y tipado.

## Qué aprendes

- Parsing CSV: delimitadores, comillas, campos multilínea
- Generación de código: producir SQL válido y seguro (escape de valores)
- Inferencia de tipos básica (números vs. texto)

## Preguntas guía

1. ¿Qué problema resuelve?
2. ¿Qué aprendí?
3. ¿Qué parte fue difícil?
4. ¿Qué haría diferente?
