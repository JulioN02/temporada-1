# 04 · Log Analyzer

Proyecto rápido de 1–3 días. Documentación en Obsidian → `Proyectos rápidos/Proyectos Rápidos.md`.

Estado: 🔲 Pendiente (idea)

## Qué hace

Dado un archivo `server.log`, produce un resumen: Requests, Errors, 404s, 500s y latencia promedio.

## Qué problema resuelve

Entender qué pasó en un servidor leyendo un log, sin herramientas de análisis externas.

## Qué aprendes

- Parsing de logs: estructura de líneas, extracción de campos
- Estadística básica: conteos, promedios, percentiles de latencia
- Lectura de archivos grandes de forma eficiente

## Preguntas guía

1. ¿Qué problema resuelve?
2. ¿Qué aprendí?
3. ¿Qué parte fue difícil?
4. ¿Qué haría diferente?
