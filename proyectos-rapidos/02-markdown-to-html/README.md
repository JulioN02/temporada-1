# 02 · Markdown → HTML

Proyecto rápido de 1–3 días. Documentación en Obsidian → `Proyectos rápidos/Proyectos Rápidos.md`.

Estado: 💡 Idea

## Qué hace

Convierte Markdown en HTML. Como extensión: pasar el HTML por una plantilla para generar PDF.

## Qué problema resuelve

Generar documentación o páginas a partir de notas Markdown sin depender de una herramienta cerrada.

## Qué aprendes

- Parser: analizar una sintaxis línea por línea y por bloques
- Transformación: de un formato (Markdown) a otro (HTML)
- Plantillas: inyectar contenido transformado en un layout

## Preguntas guía

1. ¿Qué problema resuelve?
2. ¿Qué aprendí?
3. ¿Qué parte fue difícil?
4. ¿Qué haría diferente?
