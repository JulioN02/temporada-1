🤔 ¿Qué es un ORM? (en 10 segundos)

Traduce entre dos mundos: las filas de una base de datos y los objetos de tu código. Lo hace con 3 mecánicas:

🧭 Mapping
Conecta la tabla users con una clase User. Un descriptor declara columnas y tipos.
⚙️ Query generation
Cada llamada arma el SQL con ? en vez de pegar valores. Así la inyección SQL es imposible.
🧬 Hydration
Convierte filas en objetos reales: 1 → true, fecha ISO → Date.
